# دليل المستخدم باللغة العربية (Arabic RTL Guide)

- **الإصدار:** مرشح الإطلاق النهائي (الخطوات 00–21)
- **التصنيف الافتراضي:** `Preliminary / أولي` *(كافة المخرجات استشارية وأولية وتستلزم مراجعة واعتماد مهندس مرخص قبل التنفيذ أو التقديم الرسمي.)*

---

## 1. متطلبات التشغيل والتثبيت على Windows 10/11 (حساب جديد)

### البرامج الأساسية المطلوبة
1. **Python 3.12** (64 بت — مع تفعيل خيار *Add python.exe to PATH*؛ يدعم `Python 3.11+`).
2. **Node.js 20 LTS أو أحدث** (يتضمن `npm`).
3. **Git for Windows**.

### البرامج الاختيارية (حسب الحاجة)
- **Tesseract OCR** مع حزمتي اللغة العربية (`ara`) والإنجليزية (`eng`): يُطلب فقط لقراءة ملفات PDF الممسوحة ضوئياً والصور (`TESSERACT_CMD` في `.env`).
- **ODA File Converter**: يُطلب فقط للتحويل بين صيغتي `.dwg` و `.dxf` (يُحمَّل مباشرة من Open Design Alliance بعد قبول رخصته، ويمكن ضبط مساره في `ODA_FILE_CONVERTER_PATH`).

### خطوات التثبيت والتشغيل لأول مرة (PowerShell)
```powershell
git clone https://github.com/mohokok/ai-engineering-agent.git
cd ai-engineering-agent
Copy-Item .env.example .env

cd backend
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
cd ..

cd frontend
npm.cmd install
cd ..

.\scripts\start.bat
```

بعد ظهور رسالة جاهزية الخادمين، افتح الرابط `http://127.0.0.1:5173`. يتم تطبيق ترقيات قاعدة البيانات تلقائياً عند التشغيل وإنشاء قاعدة البيانات `workspaces\engineering_agent.db` وملف السجل الدوّار `workspaces\agent.log`.

## 2. الأمان وإعداد مفتاح Gemini

1. **ربط محلي صارم:** يعمل الخادم الخلفي حصراً على `127.0.0.1:8000` (ويتم رفض أي ربط شبكي عام مثل `0.0.0.0`)، مع تقييد `CORS` لمصدر الواجهة المحلية فقط.
2. **مفتاح Gemini API (اختياري):** تعمل جميع الوحدات الهندسية الحتمية بـ `0` توكن بدون حاجة لأي مفتاح. لتفعيل تحليل المهام النصية أو الصياغة الاختيارية بالذكاء الاصطناعي:
   - انتقل إلى تبويب **إعدادات Gemini والمزودين والنظام**.
   - أدخل **مفتاح Gemini API مصرحاً به من Google AI Studio** (ملاحظة: اشتراك Gemini الاستهلاكي العادي لا يتضمن وصولاً إلى API).
   - اضغط **حفظ المفتاح في Windows Credential Manager** (لا يُخزن المفتاح أبداً في `.env` أو قاعدة البيانات أو السجلات أو النسخ الاحتياطية).
   - اضغط **تحديث النماذج الحية** ثم **اختبار الاتصال**، واضبط حدود الاستهلاك اليومية والشهرية.
3. **سجل الأحداث المحلي (`agent.log`):** تُحفظ السجلات المهيكلة بصيغة JSONL الدوّارة (`5 MB × 5`) في `<repo>\workspaces\agent.log` مع تنقيح تلقائي للمفاتيح وبيانات العميل، ودون أي عارض سجلات عبر المتصفح أو إرسال خارجي. عند حدوث أي خطأ يظهر رمز التتبع `[ref: ...]` لمراجعته في الملف المحلي.

## 3. شرح تبويبات النظام الـ 15

1. **المشاريع والملفات:** إنشاء المشاريع بالعربية أو الإنجليزية مع إنشاء المجلدات القياسية الـ 12 تلقائياً (`01_Input_Documents` .. `12_Revision_History`). الملفات الأصلية المرفوعة تُبصم بـ SHA-256 وتُقفل للقراءة فقط، وإعادة الرفع تنشئ إصدارات جديدة دون المساس بالأصل. بعد الاستخراج الحتمي لملفات CAD، يجب تأكيد وحدة الرسم (`m` أو `mm` أو `cm`) يدوياً.
2. **المهام والتكليفات:** كتابة تكليف هندسي بالعربية أو الإنجليزية مع إرفاق الملفات وتحديد التصنيف المطلوب ليقوم المنسق (Orchestrator v0) بفهم التكليف وتحديد المخرجات والافتراضات.
3. **البحث وسجل المصادر:** إجراء بحث منضبط يعطي الأولوية للأنظمة والهيئات الرسمية أو إرفاق ملفات المالك كمرجع `owner_provided` مع عزل صفحات الويب غير الموثوقة.
4. **مكتبة المعايير:** حفظ بيانات المعايير التي يزودها المالك أو رفع ملفاتها (PDF/DOCX/TXT)، وتأكيد بيانات الإصدار والحالة (`ساري / منسوخ / مسحوب / غير معروف`)، وربط الإحلال والنسخ المحدثة، وحفظ مقتطفات قصيرة (≤ 300 حرف فقط)، وتصدير سجل المعايير بصيغ DOCX و PDF و XLSX.
5. **تكييف / حريق / صحة (Preflight):** لتحضير المدخلات وفحص مخرجات البرمجيات المعتمدة فقط (`Carrier HAP` / `Elite Fire` / `CONTAM`) بوسم `أولي`. لا تُذكر أي أكواد مثل WHO أو FGI أو NFPA أو ASHRAE إلا عند ربطها بمعيار ساري في مكتبة المعايير أو سجل بحث مراجع، وإلا يظهر `'no verified standard on file - verify against the locally adopted code'`، وتُمنع النتائج عند نقص المدخلات بوسم `'not provided'`.
6. **الإنشائي (I/O Support):** لفحص تجميع الأحمال وتراكبات أحمال المالك والإحصاء الساكن البسيط للكمرات (`UDL` / `Point` / `Cantilever`) وفحص مخرجات البرامج التجارية مثل `ETABS` و `SAP2000` و `SAFE` **دون تصميم مقاطع أو تسليح ودون اعتماد أمان**، وبمراجعة إلزامية من مهندس إنشائي مرخص.
7. **التقارير والمخرجات:** توليد تقارير المراجعة الفنية بالعربية RTL أو الإنجليزية LTR (`DOCX` و `PDF`) مع فصل الحقائق المؤكدة عن مخرجات OCR غير المتحققة والافتراضات، وتحميل كافة المخرجات ببصمة SHA-256.
8. **جداول الكميات (BOQ):** استيراد الكميات من DXF/IFC/XLSX/PDF بعد تأكيد الوحدات، منع أسعار الوحدات غير المسندة لمصدر، تحديد العملة، إجراء فحوصات التكرار والحساب، وتصدير CSV و XLSX بصيغ Excel حية.
9. **الرسم الهندسي (Parametric CAD):** تعديل النموذج البارامتري بالمليمتر وتأكيده لتوليد ملفات `DXF` أصلية + `PDF` بمقياس حقيقي + جداول الأبواب والشبابيك والتشطيبات مع فحص استرداد دائري (`Round-trip check`).
10. **الحسابات الهندسية (MEP):** حساب جداول الأحمال الكهربائية وتحديد مقاطع الكابلات وهبوط الجهد واحتياج المياه ومقاسات المواسير مع طباعة المعادلات والمصادر وتصدير DOCX و PDF و XLSX.
11. **المواصفات الفنية:** توليد مواصفات مرتبطة فعلياً ببنود BOQ وجداول الرسومات والمصادر الموثقة مع اعتماد المالك لأي فقرات مصاغة اختيارياً بالذكاء الاصطناعي.
12. **المقارنات الفنية:** مصفوفة مقارنة دقيقة باستخدام `Decimal` لجميع المحاور الهندسية والمالية، مع فحص الشروط الإلزامية والوحدات وتسجيل قرار المالك الصريح.
13. **الجدولة والمسار الحرج:** بناء هيكل تجزئة العمل (WBS) وحساب المسار الحرج (CPM) وفق تقويم المالك (بما في ذلك عطلة نهاية الأسبوع الليبية الجمعة–السبت والعطلات الرسمية المدخلة)، ومنع الفروع ناقصة المدة بوسم `'not provided'`، مع مقارنة الخط المرجعي وتصدير مخطط جانت PDF و XLSX.
14. **الجودة وسجل القضايا (QA):** تشغيل وكيل الجودة المستقل المعزول عن استدلال الذكاء الاصطناعي لإعادة احتساب المعادلات وكشف الأخطاء الهندسية أو المعايير المنسوخة أو غير الموثقة أو المخرجات الناقصة، ولا يُعتمد التكليف قبل إغلاق القضايا وإعادة تشغيل الجودة بنجاح.
15. **إعدادات النظام والنسخ الاحتياطي والاستعادة:** مراجعة عنوان الربط المحلي (`127.0.0.1`) وموقع ملف السجل (`workspaces\agent.log`)، وإنشاء نسخة احتياطية مضغوطة (ZIP + بصمة SHA-256 لقاعدة البيانات وملفات المشروع مع استبعاد مفاتيح keyring)، وإجراء فحص جاف (`Dry-Run`) قبل الاستعادة أو استخدام سطر الأوامر:
    ```powershell
    cd backend
    .\.venv\Scripts\python.exe -m app.cli_backup backup --label pre_delivery
    .\.venv\Scripts\python.exe -m app.cli_backup restore --archive ..\workspaces\_backups\backup_...zip --dry-run
    ```

## 4. القيود المعروفة واستكشاف الأخطاء

- عند عدم تثبيت `Tesseract` أو `ODA File Converter` تبقى كافة الأدوات الحتمية الأخرى فعالة بشكل كامل، وتظهر رسالة توجيهية واضحة (`HTTP 400`) عند طلب OCR أو تحويل `.dwg` فقط.
- في حال انتهاء الحصة أو انقطاع الإنترنت عن Gemini، تستمر كل الحسابات والتقارير والرسومات والجدولة وفحص الجودة والنسخ الاحتياطي بالعمل بالكامل محلياً بـ `0` توكن.
